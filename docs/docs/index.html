General

WinLabeler is a small Windows tray app that shows a rounded label, for example "Work" or "Email", on the desktop you are looking at. Every virtual desktop has its own name, color and screen corner.

Why use it

  • See where you are. Windows shows no name or number for virtual desktops. The label does.
  • Your names. Rename a desktop with a double-click. Color it with 11 presets or any custom color.
  • Stays out of the way. Drag it to one of six spots on the screen; it snaps there.
  • Launch a workplace. One click on the label opens your list of workplaces, each running your own commands.
  • Private. Settings stay in %AppData%\WinLabeler\settings.json. There is no network code in the app.

New here? Start with Installation, then see Using the label for everything you can click.

How it works

How it works

WinLabeler runs one label window and moves it to whichever virtual desktop is active, filling it with that desktop's saved settings.

  1. A timer fires every 250 ms and reads the list of desktop IDs and the current desktop from the Windows registry.
  2. Because the registry value can be stale right after you sign in, the app also asks Windows which desktop other visible windows are on and prefers that answer.
  3. The desktop's ID (a GUID) is the key into your settings. Its name, color and corner are applied to the label.
  4. The label window is then pinned to the desktop you are viewing, so it follows you from desktop to desktop.
Windows registry (desktop IDs, current desktop)
        |  every 250 ms
        v
WinLabeler picks the active desktop
        |-- reads Label, Color, Corner from settings.json
        v
the single label window is moved onto that desktop

The app finds the current desktop by reading undocumented registry values. Microsoft may change them between Windows versions. If labels don't switch correctly on your version, see Troubleshooting.

GeneralInstallation

Installation

There are two ways to get WinLabeler: use the ready-made exe, or build it yourself.

From the exe

  1. Install the .NET 10 Desktop Runtime (x64) if you don't have it.
  2. Download WinLabeler.exe (also in the repository root and on the Releases page).
  3. Put it in a permanent folder such as C:\Tools\WinLabeler and run it.

The exe is not code-signed, so SmartScreen may warn you. Click More info, then Run anyway.

From source

winget install Microsoft.DotNet.SDK.10
git clone https://github.com/IG-onGit/WinLabeler.git
cd WinLabeler
build.bat

The exe is created at publish\WinLabeler.exe. build.bat runs this command:

dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish

For a build that runs without the .NET runtime installed, change --self-contained false to --self-contained true in build.bat. The file will be much larger.

Uninstall

  1. Right-click the label and untick Start with Windows.
  2. Right-click the label and choose Exit.
  3. Delete the exe. Optionally delete %AppData%\WinLabeler to remove your settings.
How it worksConfiguration

Configuration

Everything is saved automatically to %AppData%\WinLabeler\settings.json. You can also edit the file by hand while WinLabeler is not running.

{
  "AlwaysOnTop": true,
  "RememberLabels": true,
  "Desktops": {
    "<desktop-guid>": {
      "Label": "Work",
      "Color": "#2D6CDF",
      "Corner": "BottomCenter"
    }
  },
  "Workplaces": [
    { "Label": "Work", "Command": "code C:\\Work\\my-app", "Color": "#2D6CDF" }
  ]
}

Start with Windows

This option adds a WinLabeler value under the registry key below, pointing at the exe's current path. Don't move the exe afterwards, or toggle the option off and on again after moving it.

HKCU\Software\Microsoft\Windows\CurrentVersion\Run

Using the label

The label is the whole interface. Everything else lives in its right-click menu.

ActionHow
Open the workplace listClick the label once
Rename the labelDouble-click it, type the name, press Enter (Esc cancels). Or right-click, then Rename
Move the labelDrag it. It snaps to the nearest of six spots: top or bottom, left, center or right
Change the colorRight-click, then Color (11 presets or Custom...)
Keep above windowsRight-click, then Always on top
Keep labels between runsRight-click, then Remember labels
Start with WindowsRight-click, then Start with Windows
QuitRight-click the label or the tray icon, then Exit

The tray icon menu has Always on top, Start with Windows and Exit.

Only one instance runs at a time. Starting WinLabeler a second time does nothing.

ConfigurationWorkplaces

Workplaces

A workplace is a label, a color and a list of commands. Pick one from the list and WinLabeler runs the commands and labels the current desktop with that workplace's name and color.

Use a workplace

Click the label once. A list opens in the middle of the screen with Manage on top, then one row per workplace in its own color. Click a row to run it. Press Esc or click elsewhere to dismiss the list.

Manage workplaces

Choose Manage to open the Workplace window. The left side lists your options. On the right you set the Label, the Label color and the Command line code, then save or delete the option.

Writing commands

Write one command per line. WinLabeler saves them to a temporary batch file, runs it through cmd.exe with no console window, then deletes the file. Plain command lines get a call prefix automatically, so tools that are .cmd files (such as code) don't stop the rest of the script. Lines starting with :, @, rem, if, for, goto or a parenthesis are left as written.

code C:\Work\my-app
start https://github.com

An option with empty commands does nothing when clicked. If starting the commands fails, a warning with the error message is shown.

Troubleshooting

Common problems and what to try.

I don't see the label

Look at the corner above the taskbar and at the tray icon. With Always on top off, windows can cover the label.

Labels don't switch when I change desktop

WinLabeler relies on undocumented registry values that can differ between Windows versions. For the first minute after it starts, it writes a short diagnostic log to %AppData%\WinLabeler\startup.log, which shows how many desktops it found and which one it thinks is current.

A label shows just its number after renaming

You saved an empty name. An empty name means "use the default", which is the desktop number.

build.bat says ".NET SDK was not found"

Install the SDK, then reopen your terminal.

Build error about the target framework

Your SDK is older than the project expects. Change net10.0-windows in WinLabeler.csproj to match it, for example net8.0-windows.

Start with Windows stopped working

The registry entry points at the exe's old path. Toggle Start with Windows off and on again.

System requirements

WinLabeler is a single exe with no server or account.

To run it

ItemRequirement
Operating systemWindows 10 or 11, 64-bit (developed and tested on Windows 10 LTSC 1809)
Runtime.NET 10 Desktop Runtime (x64), unless you build a self-contained exe
NetworkNone. No server is involved
