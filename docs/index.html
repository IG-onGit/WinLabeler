Workplaces

Automated workspace setup

Turn any virtual desktop into a ready workspace. A workplace is a label, a color and a list of commands that run through cmd.exe.

  • Open your editor, browser and tools with one click
  • The current desktop is labeled with the workplace you launched
  • One command per line, edited in a small built-in manager

Features

Automation first, labels to keep you oriented

WinSpace starts everything you need and names each virtual desktop, so you never lose your place.

Workplace launcher

Click the label for your workplaces. Each one runs your own commands and labels the desktop to match.

One label per desktop

Each virtual desktop remembers its own name, color and screen position. Switch desktops and the label follows you.

Rename in place

Double-click the label, type a name, press Enter. Esc cancels. An empty name falls back to the desktop number.

Drag and snap

Drag the label anywhere and it snaps to the nearest of six spots: top or bottom, left, center or right.

Your colors

Pick from 11 preset colors or open the color picker for any custom shade, separately for every desktop.

Local and private

Settings live in a JSON file in your AppData folder. The app has no network code and no account.

How it works

Set it up once, launch it forever

Three steps from install to a ready workspace.

  1. Define a workplace

    Run WinSpace, click the label and open Manage. Give the workplace a name, a color and one command per line.

  2. Click to launch

    Pick the workplace from the list. WinSpace runs your commands and starts your editor, browser and tools.

  3. Stay oriented

    The desktop is labeled and colored to match. Switch desktops and each one keeps its own name, color and corner.

FAQ

Questions people ask first

Is WinSpace free?

Yes. WinSpace is open source under the MIT license, so you can use, change and share it at no cost.

Which versions of Windows does it support?

Windows 10 or 11, 64-bit. It was developed and tested on Windows 10 LTSC 1809. It finds the current desktop through undocumented registry values, which Microsoft may change between Windows versions.

Do I need to install .NET?

The released exe needs the .NET 10 Desktop Runtime (x64). If you build from source you can switch to a self-contained build that runs without the runtime, at the cost of a much larger file.

Does WinSpace send any data anywhere?

No. The app contains no network code. Your labels and workplaces are stored in a settings.json file in your own %AppData%\WinSpace folder.
